# ⌨️ Speed-Type

A sleek and powerful **web-based typing speed application** built with React.  
Measure your typing speed with **real-time progress tracking**, **accuracy metrics**, and a **customizable experience** designed for beginners and pros alike.

🌐 [Live Demo](https://speed-type-smoky.vercel.app/)

---

## ✨ Features

- ⚡ Real-time **WPM (Words Per Minute)** and **accuracy** tracking  
- ⏱️ Accurate **time tracking** with countdown and stopwatch modes  
- 📈 Dynamic **progress indicators** while typing  
- 🎯 Multiple **difficulty levels** and typing challenges  
- 🎨 Clean, responsive, and **customizable UI** using TailwindCSS  

---

## 🛠 Tech Stack

| Layer   | Technologies              |
|---------|---------------------------|
| Client  | React, Redux, TailwindCSS |
| Server  | Node.js                   |
